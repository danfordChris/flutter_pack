# flutter_pack

`flutter_pack` is a utility package for Flutter that provides:
- Database management helpers with migration support
- Model and repository code generators
- String and date extensions
- Shared preferences helpers
- Project scaffolding utilities

This package helps you speed up Flutter app development by reducing boilerplate code and providing reusable utilities for common tasks.

## Features

- 🔹 Database manager with migration support
- 🔹 Preference manager for shared preferences
- 🔹 Generators for models, repositories, and project scaffolding
- 🔹 Handy string/date extensions
- 🔹 Utility helpers for Flutter apps

## Getting started

Add this to your `pubspec.yaml`:

```yaml
dependencies:
  flutter_pack: ^1.1.0
